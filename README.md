# WOLCOM

WOLCOM is a web application concept that merges the real-time group chat interface of modern messaging apps with the topic-based anonymity of internet forums. 

## Project Overview
This platform was built to create a space where people can connect based on shared interests and honest communication, without the social pressures associated with public profiles, personal brands, or follower counts. 

Key features include:
* **Complete Anonymity:** Users authenticate to access the platform, but identities remain strictly hidden within the chat interface. No usernames are attached to outgoing messages.
* **Public Groups Only:** To maintain an open and inclusive community, there is no direct or private messaging. All communication occurs in topic-specific public groups.
* **Minimalist UI:** A strict black-and-white design layout keeps the user's focus entirely on the text and the conversation.

## Current Technology Stack
* HTML5
* CSS3 (Flexbox, Fixed Positioning, CSS Box Model)

## Development Roadmap
This initial version was built as a foundational frontend project to establish the core UI and practice structural HTML/CSS layouts. The repository is actively maintained and will be updated as the project scales. 

Future planned implementations include:
* **JavaScript Integration:** To manage DOM manipulation, input handling, and dynamic UI updates.
* **Backend Infrastructure:** Implementing a server (Node.js/Python) and a database to handle user authentication, session management, and chat history storage.
* **WebSockets:** Upgrading the architecture to support bi-directional, real-time message broadcasting.

## Local Setup
As this is currently a static frontend prototype, no server or dependency installation is required to view the interface.

1. Clone or download this repository to your local machine.
2. Navigate to the project directory.
3. Open the `wolcom.html` file in any modern web browser.
